SAENG SOFTWARE SST — FINALIZADOR DEFINITIVO
===========================================

OBJETIVO
Este pacote consolida os ajustes conhecidos do SAENG Software SST V2 e cria uma instalação paralela em:

C:\SAENG_Software_SST_FINAL

A instalação atual C:\SAENG_Software_SST_V2 não é apagada.

COMO EXECUTAR
1. Feche o navegador do SAENG e qualquer janela preta do servidor.
2. Clique com o botão direito em INSTALAR_SAENG_FINAL_DEFINITIVO.cmd.
3. Escolha Executar como administrador.
4. Aguarde a compilação e os testes.

A instalação somente é aprovada quando aparecer:

SAENG SOFTWARE SST FINAL — INSTALAÇÃO APROVADA

ARQUIVOS GERADOS
- C:\SAENG_Software_SST_FINAL
- C:\SAENG_Software_SST_BACKUP_FINAL_AAAAMMDD_HHMMSS
- C:\SAENG_Software_SST_FINAL_CODIGO.zip
- Atalho SAENG Software SST na Área de Trabalho

SEGURANÇA
Este pacote não contém certificado, senha, banco, procuração ou dados pessoais.
O certificado instalado no Windows é carregado somente em memória durante a sessão.
Nenhum PFX/P12 é gravado na pasta do programa.
